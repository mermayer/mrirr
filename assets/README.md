# Media assets

## Product images

The images in `product` are clean presentation renders based on photographs of
the working MRIRR prototype. They are intended to show the device layout more
clearly than the workshop reference photographs.

## Web interface images

The images in `web-ui` were rendered from the real MRIRR configuration
interface. All visible device, network, zone, title and artist values are
fictional demonstration data.

Do not replace these images with screenshots from a configured personal device
without first checking them for Wi-Fi credentials, IP addresses, Roon data and
other identifying information.
